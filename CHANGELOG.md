# Changelog

## 0.1.0

- First release for GitHub Copilot: the Zenrows MCP server (OAuth sign-in) and nine skills: `using-zenrows`, `getting-started`, `scrape-webpage`, `extract-structured-data`, `batch`, `crawl`, `map`, `browser-automation` and `capture-api-calls`. The skills come from [claude-zenrows](https://github.com/ZenRows/claude-zenrows) 0.1.3, with setup steps for Copilot, except `crawl`, which runs Zenrows Crawl as a background job (`crawl_create`, `crawl_wait`, `crawl_results`) as in [openai-zenrows](https://github.com/ZenRows/openai-zenrows).
